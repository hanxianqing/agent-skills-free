# Shorts shot-list template

Copy this file per video. Fill in your own product, hook, captions
and subtitles. One row per image. Keep 4–7 images (fewer feels
empty, more feels rushed at 20–45 s).

## Header (fill in)

- Product: ___________________________
- Price: $_____ | Buy link (channel Shop page): _______________
- Format (circle one): product tour / pain-point solved / countdown
- Narration script (write it FIRST — the video is cut to the audio):
  ___________________________________________________________
- Narration duration: ______ s | Images: ______ | Seconds per image: ______

## Hook card (first 1.5 s)

- Hook text (problem or number, NOT the product name):
  ___________________________________________________________
- Example that worked for us: "TEACHERS: STOP MAKING GAMES FROM SCRATCH"

## Segments

| # | Image file | Big title (top, auto-fit from 66 pt) | Subtitle line(s) (42 pt, 1–2 lines) | Camera move (cycle: zoom in → zoom out → pan right → pan left) |
|---|------------|--------------------------------------|--------------------------------------|---------------------------------------------------------------|
| 1 | | | | zoom in |
| 2 | | | | zoom out |
| 3 | | | | pan right |
| 4 | | | | pan left |
| 5 | | | | zoom in |
| 6 | | | | zoom out |
| 7 | | | | pan right |

Rules:
- Title = one short phrase per image (the benefit, not a feature
  list). Subtitles = the exact spoken words for that segment.
- Two segments in a row must never share a camera move.
- If a segment's subtitle needs more than 2 lines, split the segment.

## End card (voiceover, last 2 s)

- Spoken line (always the same): "Shop link on my channel page."
- Never say "link in the description" — Shorts description links
  are not clickable.
